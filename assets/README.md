# Assets Directory

This directory contains media files for the Music Video Maker Game.

## Required Files

### Audio
- `demo-song.mp3` - The background music track (you need to add your own MP3 file)

## Adding Your Own Audio

1. Find an MP3 file you want to use (ensure you have rights to use it)
2. Copy it to this directory
3. Rename it to `demo-song.mp3` or update the audio source in `music-video-maker.html`

## Recommended Audio Specifications

- Format: MP3
- Duration: 30-90 seconds (for best gameplay experience)
- Quality: 128kbps or higher

## Note

Since we can't include copyrighted music, you'll need to add your own audio file. You can:
- Use royalty-free music from sites like FreeMusicArchive or Incompetech
- Create your own music
- Use Creative Commons licensed tracks

For testing purposes, the game will still load without an audio file, but you'll need to add one for the full experience.
